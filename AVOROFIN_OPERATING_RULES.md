# AvoroFin Operating Rules (P0 recovery, 2026-09-28)

1. **Availability first.** Keep the site and Telegram usable for owner decisions.
2. **Known numeric financial data must remain visible.** Do not hide known WB/Ozon amounts.
3. **Unknown ≠ zero.** Missing/incomplete data is null / н/д / unavailable — never a trusted `0`.
4. **PRELIMINARY is metadata**, not permission to discard known numbers. Show the amount and label PRELIMINARY.
5. **Historical repair must not hold site availability hostage.** Fix current days/months first.
6. **Failed deploy/repair → restore runtime first**, investigate second.
7. **One task = diagnose → fix → test → deploy → verify.** Site and Telegram in the same block when finances change.
8. **No micro-version proliferation** without a real hard boundary.
9. **Production is never the first place** a known legacy state is tested.
10. **Site and Telegram share one financial semantic contract** (same CASE 1–4 display rules).
